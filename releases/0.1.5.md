# RustClipSync Keyboard 0.1.5

- Upgrade to protocol 3 / RustClipSync Server 3.0.0: report direction and pause before receiving, with fenced WebSocket sessions and authenticated HTTP fallback.
- Automatically cancel and safely skip conflicting or expired uploads. Preserve the current clipboard and resume with fresh copy events instead of asking to overwrite remote content.
- Preserve sensitive flags when editing and copying clipboard history; disallowed marked copies are not read for upload.
- Retain the upstream Fcitx5 input method and voice input support. The old clipboard bridge has been replaced by the dedicated RustClipSync module.

Requires RustClipSync Server 3.0.0 / protocol 3. This is an ARM64 APK signed with the same certificate as 0.1.4; versionCode increases from 132 to 142.

中文：新增协议 3 同步方向与暂停上报、WS/HTTP 降级及会话隔离；冲突和过期上传自动安全跳过，保留当前剪贴板，继续同步新的复制事件。修复历史编辑后复制丢失敏感标记。保留输入法和语音输入功能。需服务端 3.0.0；沿用 0.1.4 签名，支持覆盖升级。
